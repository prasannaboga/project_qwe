- (constraint) Convention AGENTS.md: No business logic in handlers; all domain ops through services/todo_service.py
- (version) Stack: Python >=3.14, FastAPI 0.141.1, SQLAlchemy 2.0.51, mcp[cli] >=2.2.0,<2.3.0, Pydantic 2.x
- (decision) AD-1: Lightweight Ports & Adapters paradigm. src/project_qwe/mcp/todos/ is an inbound protocol adapter delegating all domain logic to services/todo_service.py. Zero direct ORM queries in MCP handlers.
- (decision) AD-2: FastAPI integration via ASGI Sub-Application Mount (app.mount('/mcp/todos', sub_app)). Bypasses router middleware and isolates raw SSE streaming and JSON-RPC dispatch without OpenAPI schema pollution.
- (decision) AD-3: Strictly operation-scoped database sessions. The persistent SSE stream maintains zero database connections; sessions are ephemeral and scoped via with SessionLocal() inside individual tool callbacks.
- (decision) AD-4: Operational Invariant: MCP SseServerTransport stores session stream writers in-process. In multi-instance deployments behind AWS ALB, target-group cookie stickiness is required for /mcp/*; single-instance deployments require no stickiness.
- (decision) AD-5: Service Layer Invariant: todo_service must be extended with search_todos(db, query, limit) and compound sorting support in get_todos rather than filtering in MCP handlers.
